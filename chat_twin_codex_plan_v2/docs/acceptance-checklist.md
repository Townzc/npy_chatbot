# 端到端验收清单

这是待实现的验收，不是已通过报告。通用工程测试与私有 QQ/GPU 测试分开记录。

## 主闭环

- [ ] 创建档案 A、B；绑定不同虚构目标身份，确保不串用。
- [ ] A 导入 QQ 与微信格式记录，检查发送者、时间、类型、来源和重复报告。
- [ ] 使用一份“导出者与训练本人不同”的样例核查标签。
- [ ] 构建完整片段的 train/validation/test，确认无窗口交叉和未来记忆。
- [ ] 真实训练一个 LoRA，保存后由新进程加载，显示底座及 adapter 标识。
- [ ] 网页试聊使用所选模型和关系记忆，与基线对照。
- [ ] 绑定受控 QQ 原私聊；实际账号和目标标识正确。
- [ ] 开启通知精确为“对方已切换为ai模式”，成功确认前零 AI 回复。
- [ ] 生成中接管；旧候选失效，固定发“本人已接管”。
- [ ] 接管页面版本过期也能停止；断网通知失败也不恢复 AI。
- [ ] 模式通知、自身回声先于回执均不触发循环。
- [ ] 认领后发起前接管，不得在停止确认后新发起旧 AI 请求。
- [ ] 在途请求超时进入 unknown，不重发，也不误称能保证接收顺序。
- [ ] 更换档案/联系人创建新 Binding，旧候选绝不发到新目标。
- [ ] 数据库事务提交附近崩溃不丢接管通知意图。
- [ ] 从备份恢复，验证数据库、文件、模型记录与当前模式。
- [ ] 新环境按 README 完成安装；无 GPU 也可运行核心和示例。
- [ ] 至少 7 天有效真实试运行，已知限制与支持矩阵一致。
