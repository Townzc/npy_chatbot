旧代码+升级前备份已在独立环境实际回滚，通过固定提交版本复核，不对新版数据库原地降级。详见[回滚证据](evidence/application-rollback-2026-10-26.md)。

GitHub当前OAuth连接缺`workflow`权限，首次上传可执行工作流被拒绝。已将CI配置保留为`ci/github-actions.template.yml`，源码推送成功；没有换凭证绕过权限。用户后续授予相应权限或自行安装模板后才可启用Actions，当前不声称远程CI成功。

最新[真实导入与只读桥证据](evidence/real-qq-export-and-probe-2026-10-27.md)包含578条去重、209条本人文字候选、网页37/14/5快照、冻结保留集隔离及真实私有备份恢复。只有5个最终测试窗口，不构成人工质量门槛。

发布审查前尚需：Qwen CUDA和B0–B3独立评分；QQ原会话受控实测；手机离网/休眠；实际私人模型重部署；至少7天日志；其他数据来源实机兼容及依赖许可与漏洞复审。所有实测应记录固定版本、时间、环境与失败，不以测试数量代替质量。
