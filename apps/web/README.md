# ChatTwin Web

React + TypeScript + Vite 本地工作台。所有页面调用 FastAPI，页面中不内置聊天回答或训练结果。

```sh
pnpm install --frozen-lockfile
pnpm generate:api
pnpm build
```

API 类型来自根目录 `schemas/openapi.json`，生成到 `src/generated-api.ts`。`src/api.ts` 只对后端未细分的字典元数据做显示类型收窄，Binding、ModeStatus、ModeCommand、SandboxInput、MemoryInput 直接复用生成类型。

生产页面由后端提供，构建资产复制到 `src/chattwin/web_dist`。开发模式 `pnpm dev` 将 `/api` 代理到 `127.0.0.1:8765`；真实运行与浏览器验收优先使用后端同源入口。

已实现：本人凭证登录、加载虚构数据、创建档案和独立关系、选择绑定、B0/B1/B2/B3 对照试聊、通知与接管、导入预览/稳定 ID 选择/CSV 映射、从当前关系消息选择出处、关系记忆保存/编辑/有效期/删除、风格版本草稿与确认、身份检查、导入删除影响预览、冻结数据集与目标样本预览、实际训练环境/作业/取消/日志、私有训练包下载、模型产物登记/端点测试/启用/回滚、脱敏诊断和一致性备份下载。

接管按钮不受生成、导入、构建数据集或正在开启的请求阻断。相同失败命令重试复用 command_id；旧控制 epoch 响应不能覆盖新状态。切换绑定后，导入表单、记忆和训练报告重置，未完成的试聊请求取消。

本人访问凭证仅用于 POST `/auth/session` 换取默认一小时的短期令牌；sessionStorage 只保存短期令牌，旧版保存的本人凭证在启动时清除，凭证均不放在 URL。退出调用 DELETE 撤销会话并清理本地状态；服务重启或令牌失效后重新登录。登录/退出不改变 AI 模式，接管请求进行时暂停退出入口。没有遥测、远程字体、外部图像、HTML 聊天渲染或第三方脚本。

恢复只支持离线 CLI 到新的空目录，网页不覆盖运行数据；身份重映射目前通过 API，网页提供身份检查。QQ 原会话、手机离网接管和真实参考底座 GPU 训练需独立实机验证。模型端点测试会由用户明确点击后发送固定虚构提示，注册配置本身不调用模型。

新建档案/关系使用真实 API 顺序创建 Persona、Relationship 和默认 HUMAN 的网页 Binding，完成后刷新状态并选中该关系。已确认完成的步骤在失败重试时复用。记忆来源只从当前关系的 `/messages` 读取和选择，不要求用户猜消息 ID；目前该 API 最多返回 200 条，界面明确标注这一限制。

管理页已拆分到 `src/pages/`，公共组件在 `src/components/`。页面渲染失败由局部边界处理，底部本人接管按钮保持挂载。`pnpm format:check` 与 `pnpm build` 分别验证格式和严格类型/生产构建；后端契约更新后先重新运行 `pnpm generate:api`。

B3 仅在当前关系启用已验证的 LoRA 产物部署后可用。adapter 部署下的 B0–B2 使用配置的基础模型提供方，B3 才使用 adapter；每条回复显示实际返回模型和对照档位。

运行与维护页提供发送结果未知时的渠道核对和本人核对登记。人工结论需选择已送达/未送达、填写实际核对依据并明确确认；不会重发消息或恢复 AI。月度预算按当前 Persona 隔离，显示包含未结算预留的持久用量，并支持请求/token/估算金额限额和单价配置。预算保存校验版本，不会解除会话暂停。

导入的原会话类型默认按文件声明，未声明则保持 unknown。只有用户明确选择一对一私聊才向 mapping 写入 private；选择新文件或格式会重置确认，不把未知或群聊记录自动送入私聊训练。
